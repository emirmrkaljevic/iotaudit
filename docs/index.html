A home network audit you run yourselfOpen source, MIT, Python 3.10+

For cameras, plugs, feeders, bulbs and doorbells

Who is your smart plug talking to at three in the morning?

iotaudit watches what a device does on your own network and writes it down plainly: who it talks to, whether that traffic is encrypted, which ports are open, and what changed since last time. Each device gets a grade from A to F, a one line verdict and a single page report. Everything stays on your computer.

$ pipx install iotaudit
$ sudo iotaudit auto
Type "I OWN THIS NETWORK" to continue: I OWN THIS NETWORK
Report written to ~/iotaudit/YYYY-MM-DD/HHMMSS.html

Capturing needs root. The port scan uses nmap if it is installed. Already have a pcap from Wireshark, your router or PCAPdroid? Run iotaudit analyze capture.pcap, no root needed.

02 / How it works

First the traffic has to pass your computer.

iotaudit reads packets, so it needs to see them. There are four ways to get there, from no setup at all to taking one device fully through your laptop. All of them end in the same grade and report.

Just run itiotaudit auto
Finds devices, runs the safe checks and captures passively whatever already reaches this computer. It does not spoof anything and does not start a hotspot.
ARP, on macOS or Linuxcapture --mode arp
Pick one device from a list and iotaudit ARP spoofs only that device, so its traffic flows through your machine. ARP tables and IP forwarding are restored on exit.
Hotspot, on Linuxcapture --mode hotspot
Your laptop becomes the access point and you pair the device to it. Useful when client isolation on the main Wi-Fi would hide the device from you.
A capture you already haveiotaudit analyze file.pcap
Wireshark, OpenWrt tcpdump over SSH, PCAPdroid on Android. No root needed. Capturing at the router is the closest you get to ground truth.
03 / The grade

Every device starts at 100 and loses points for what it does.

A90 and up
B75 to 89
C60 to 74
D45 to 59
E30 to 44
Fbelow 30

A high finding costs 25 points, a medium one 10, a low one 4. Informational notes cost nothing. A capture with too little data is capped at 70, so it can never earn an A. Offline known issue hints from a curated CVE list only change the grade when the version match is exact and the severity is critical. iotaudit diff tells you when a grade gets worse between two audits.

100
− 25 telnet open on the LAN (high)
− 10 hardcoded public DNS (medium)
− 10 custom encryption, unverified (medium)
= 55, grade D
04 / Also

An MCP server, and a few rules it will not bend.

pip install "iotaudit[mcp]"
iotaudit-mcp

This starts a local MCP server over stdio, so an MCP client on your own machine can run the same audit tools: analyse a pcap, capture, scan one device, compare two saved audits, list UPnP port forwards. It is not a network service, and the live tools refuse to run until ownership is confirmed.

Reports also come as PDF, CSV or Markdown, and grades can go into Home Assistant over MQTT. Details are in the MCP page and the usage guide.

Consent and scope

iotaudit is for your own network and your own devices only. It refuses non private targets and asks you to type I OWN THIS NETWORK (or pass --i-own-this-network) before it captures. ARP spoofing a network you do not own may be illegal.

All data stays local. No account, no cloud, no telemetry. Findings are indicators based on observed traffic, not proof of wrongdoing by any vendor.

I wrote iotaudit for the cheap gadgets that end up on a home Wi-Fi. The questions are always the same, and I wanted one command that answers them without sending my network to anyone.
