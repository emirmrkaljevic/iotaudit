# Integrations

Guides for using iotaudit with a router, Home Assistant, or a phone. For a short start, see the [README](https://github.com/emirmrkaljevic/iotaudit#readme).

## [Show iotaudit results in Home Assistant](home-assistant.md)

Publish a compact grade summary over MQTT, or write a JSON file that a `command_line` sensor can read.

## [Grade devices from an OpenWrt tcpdump capture](openwrt.md)

Take a `tcpdump` capture on an OpenWrt router, copy the pcap off, and grade it with `iotaudit analyze`.

## [Phones: Android, iPhone and the web UI](phones.md)

What a phone can and cannot do, and how to use `iotaudit web` from the computer that captures.
